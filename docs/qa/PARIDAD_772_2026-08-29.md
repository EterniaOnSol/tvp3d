# Auditoria de paridad TVP 7.72

Fecha: 2026-08-29

## Criterio

Esta auditoria no considera una mecanica terminada porque se parezca a Tibia.
Solo usa `COMPROBADO` cuando el payload o la regla se obtuvo del servidor TVP,
el cliente conserva el estado y existe una prueba que detecta desalineacion o
regresion. `PARCIAL` significa que existe codigo real pero falta alguna de esas
piezas. `AUSENTE` significa que no hay recorrido utilizable.

Fuentes autoritativas revisadas:

- `servidor/src/protocolgame.cpp` para opcodes y payloads 7.72.
- `servidor/src/game.cpp`, `creature.cpp`, `player.cpp` y `monster.cpp` para
  reglas de juego, muerte, corpse y loot.
- `servidor/data/` para acciones, fluidos, NPC y datos de monstruos.
- `cliente3d/red/` y `cliente3d/ui/` para consumo, estado e interaccion.

## Flujo exacto de muerte encontrado

Esta rama no contiene `sendDeath` ni `sendReLoginWindow`. El recorrido real es:

1. `Creature::onDeath` crea splash/corpse, ejecuta eventos y deposita loot.
2. `Player::death` fija el templo como proximo login, aplica perdidas y
   blessings, restaura HP/MP y elimina condiciones.
3. Si se creo corpse, `Game::removeCreature(player, false)` retira al jugador
   de la casilla y envia a los espectadores el `0x6C` normal de remove thing.
4. La conexion del jugador no se cierra en esa ruta. Si despues recibe logout
   `0x14`, `ProtocolGame::logout` detecta que ya fue removido y desconecta.

El contrato de implementacion para el cliente es por tanto detectar que el
objeto eliminado por `0x6C` es la criatura `mi_id`, emitir un evento local de
muerte, bloquear nuevas intenciones, mostrar la accion de volver y enviar
logout `0x14` para regresar al selector. No debe esperarse ni inventarse un
opcode de muerte que este servidor no produce.

El corpse del monstruo conserva propietario de mayor dano cuando corresponde,
se abre mediante el flujo normal de contenedor y decae bajo autoridad del
servidor. La prueba viva debe verificar tambien que otro cliente no obtiene
acceso anticipado si la regla de ownership lo impide.
